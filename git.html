Git Cheat Sheet

Configure Git


git config --global user.name "Your Name"

git config --global user.email "you@example.com"

git config --list

Create Repository


git init

Check Status


git status

Add Files


git add file.txt

git add .

git add *.js

Commit


git commit -m "Add new feature"

View Commits


git log

git log --oneline

Branches


git branch

git branch feature

git switch feature

git switch -c feature

Merge


git switch main

git merge feature

Remote Repository


git remote -v

git remote add origin <repository-url>

Push


git push origin main

git push -u origin main

Pull


git pull origin main

Clone


git clone <repository-url>

Undo Changes


git restore file.txt

git restore --staged file.txt

Git Ignore


# .gitignore

node_modules/
.env
*.log
