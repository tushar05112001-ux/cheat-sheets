C Language Cheat Sheet

C is a general-purpose, procedural programming language used for system programming, operating systems, embedded systems, and application development. It provides low-level memory access along with structured programming features.

1. Basic Structure of C

Definition: A C program consists of functions, statements, and declarations. The main() function is the entry point where program execution begins. 


#include <stdio.h>

int main(void) {
    printf("Hello, World!");

    return 0;
}
  • #include: Includes a header file.
  • stdio.h: Provides standard input and output functions such as printf() and scanf().
  • main(): The function where program execution begins.
  • printf(): Displays formatted output.
  • return 0: Indicates successful program termination.

2. Variables

Definition: A variable is a named memory location used to store a value that a program can access and modify. 


int age = 24;
float price = 99.50f;
char grade = 'A';
double salary = 45000.75;
  • int: Stores integer values.
  • float: Stores floating-point values.
  • char: Stores a character value.
  • double: Stores floating-point values with more precision than float.

3. Data Types

Definition: Data types specify what kind of value a variable can represent and how that value is interpreted. 


int number = 10;
char letter = 'A';
float percentage = 85.5f;
double pi = 3.1415926535;
_Bool isActive = 1;
  • char: Represents a character or a small integer value.
  • int: Represents integer values.
  • float: Represents single-precision floating-point values.
  • double: Represents double-precision floating-point values.
  • void: Represents the absence of a value or specifies a function with no parameters.
  • _Bool: Represents the values 0 or 1. The stdbool.h header provides bool, true, and false in C99 and later.

Note: The exact size of a data type depends on the compiler and platform. Use sizeof() to check its size. 


printf("%zu", sizeof(int));

4. Constants

Definition: Constants represent values that should not be modified during normal program execution. C provides the const qualifier and macros defined using #define. 


const float PI = 3.14159f;

#define MAX_SIZE 100
  • const: Prevents modification through that variable or object expression.
  • #define: Defines a preprocessor macro.

5. Input and Output

Definition: Input and output operations allow a program to receive information from users and display results. The stdio.h header provides common input/output functions. 


#include <stdio.h>

int main(void) {
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Your age is %d", age);

    return 0;
}
  • printf(): Prints formatted output.
  • scanf(): Reads formatted input.
  • getchar(): Reads one character from standard input.
  • putchar(): Writes one character to standard output.
  • fgets(): Reads a line or part of a line from a stream.

Important: Check the return value of scanf() to ensure input was read successfully. Use fgets() when reading text containing spaces.

6. Format Specifiers

Definition: Format specifiers tell functions such as printf() and scanf() what type of value is being printed or read. 


int age = 24;
float price = 10.5f;
char grade = 'A';
double value = 3.14159;

printf("%d", age);
printf("%f", price);
printf("%c", grade);
printf("%f", value);
printf("%s", "Hello");
  • %d: Prints or reads an int.
  • %f: Prints a floating-point value; in scanf, it reads a float through a float pointer.
  • %lf: In scanf, reads a double through a double pointer. In printf, %f is used for double.
  • %c: Prints or reads a character.
  • %s: Prints or reads a character string. Ensure the destination buffer has enough space when using scanf.
  • %u: Prints or reads an unsigned int.
  • %ld: Prints or reads a long int.
  • %zu: Used for values of type size_t, such as the result of sizeof.
  • %p: Prints a pointer value.

7. Operators

Definition: Operators are symbols that perform operations on variables and values. 


int a = 10;
int b = 3;

printf("%d", a + b);
printf("%d", a - b);
printf("%d", a * b);
printf("%d", a / b);
printf("%d", a % b);
  • Arithmetic: + - * / %
  • Relational: == != > < >= <=
  • Logical: && || !
  • Assignment: = += -= *= /= %=
  • Increment and decrement: ++ --
  • Bitwise: & | ^ ~ << >>
  • Conditional: condition ? value1 : value2

Note: Integer division discards the fractional part. For example, 10 / 3 produces 3.

8. Conditions

Definition: Conditional statements allow a program to make decisions and execute different code depending on whether a condition is true or false. 


int age = 20;

if (age >= 18) {
    printf("Adult");
} else {
    printf("Minor");
}
  • if: Executes code when a condition is true.
  • else: Executes code when the if condition is false.
  • else if: Checks another condition.
  • switch: Selects a branch based on an integer, character, or enumeration value.

int choice = 2;

switch (choice) {
    case 1:
        printf("One");
        break;

    case 2:
        printf("Two");
        break;

    default:
        printf("Other");
}

9. Loops

Definition: Loops repeatedly execute a block of code while a condition remains true or until a sequence of operations is completed. 


for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}

int j = 0;

while (j < 5) {
    printf("%d\n", j);
    j++;
}

int k = 0;

do {
    printf("%d\n", k);
    k++;
} while (k < 5);
  • for: Useful when initialization, condition, and update can be written together.
  • while: Repeats while a condition is true.
  • do...while: Executes its body at least once before checking the condition.
  • break: Exits the nearest loop or switch statement.
  • continue: Skips to the next loop iteration.

10. Functions

Definition: A function is a reusable block of code that performs a specific task. It can accept parameters and return a value. 


#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main(void) {
    int result = add(5, 3);

    printf("%d", result);

    return 0;
}
  • Function declaration: Announces a function's name, return type, and parameter types.
  • Function definition: Contains the implementation of a function.
  • Parameters: Variables that receive argument values.
  • Arguments: Values supplied when calling a function.
  • return: Returns a value or ends a void function.
  • void: Indicates that a function does not return a value when used as its return type.

11. Arrays

Definition: An array stores multiple elements of the same type in contiguous memory locations. Array indexing starts at zero. 


int numbers[5] = {10, 20, 30, 40, 50};

printf("%d", numbers[0]);

numbers[1] = 25;
  • Declaration: int numbers[5]; creates an array of five integers.
  • Initialization: Assigns initial values to array elements.
  • Indexing: Accesses an element using its position.
  • Traversal: Uses a loop to process array elements.

Important: C does not automatically check array bounds. Accessing an element outside the array's valid range causes undefined behavior.

12. Strings

Definition: C does not have a built-in string data type. A string is usually stored as an array of characters terminated by the null character '\0'. 


#include <stdio.h>
#include <string.h>

int main(void) {
    char name[] = "Tushar";

    printf("%s\n", name);
    printf("%zu\n", strlen(name));

    return 0;
}
  • strlen(): Returns the number of characters before the terminating null character.
  • strcpy(): Copies a string into a destination buffer that must be large enough.
  • strcat(): Appends a string to a destination buffer with sufficient capacity.
  • strcmp(): Compares two strings lexicographically.
  • strchr(): Searches for a character in a string.

These string functions are declared in string.h. Ensure destination buffers are large enough to avoid writing beyond their boundaries.

13. Pointers

Definition: A pointer is a variable that stores the address of an object or function, or a null pointer value. Pointers are commonly used for arrays, dynamic memory, and passing addresses to functions. 


int number = 10;

int *ptr = &number;

printf("%d\n", number);
printf("%p\n", (void *)ptr);
printf("%d\n", *ptr);
  • &: The address-of operator obtains an object's address.
  • * in a declaration: Declares a pointer type, such as int *ptr.
  • * in an expression: Dereferences a valid pointer to access the pointed-to object.
  • NULL: Represents a null pointer constant.

Important: Never dereference a null, uninitialized, or otherwise invalid pointer.

14. Structures

Definition: A structure groups variables of different data types under one type. It is useful for representing related information. 


#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float marks;
};

int main(void) {
    struct Student s = {"Tushar", 24, 85.5f};

    printf("%s\n", s.name);
    printf("%d\n", s.age);
    printf("%.1f\n", s.marks);

    return 0;
}
  • struct: Defines a structure type.
  • Dot operator (.): Accesses a member of a structure object.
  • Arrow operator (->): Accesses a member through a pointer to a structure.
  • typedef: Creates a type alias.

15. Unions and Enumerations

Union definition: A union allows different members to share the same memory storage. 


union Data {
    int number;
    float value;
};

union Data data;

data.number = 10;

Enumeration definition: An enum defines named integer constants that make code easier to read. 


enum Day {
    MONDAY,
    TUESDAY,
    WEDNESDAY
};

enum Day today = TUESDAY;

16. Dynamic Memory Allocation

Definition: Dynamic memory allocation allows a program to request memory while it is running. The functions are declared in stdlib.h. 


#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *numbers = malloc(5 * sizeof *numbers);

    if (numbers == NULL) {
        return 1;
    }

    numbers[0] = 10;

    printf("%d\n", numbers[0]);

    free(numbers);

    return 0;
}
  • malloc(): Allocates memory without initializing its contents.
  • calloc(): Allocates memory for multiple elements and initializes all bytes to zero.
  • realloc(): Changes the size of an allocated memory block.
  • free(): Releases dynamically allocated memory.

Always check allocation results before using the returned pointer. Release allocated memory when it is no longer needed, and never access it after it has been freed.

17. File Handling

Definition: File handling allows a program to create, read, write, and close files stored on a device. 


#include <stdio.h>

int main(void) {
    FILE *file = fopen("data.txt", "w");

    if (file == NULL) {
        perror("Unable to open file");
        return 1;
    }

    fprintf(file, "Hello, C!");

    fclose(file);

    return 0;
}
  • fopen(): Opens a file using a specified mode.
  • fprintf(): Writes formatted text to a file.
  • fscanf(): Reads formatted data from a file.
  • fgets(): Reads a line or part of a line from a file.
  • fclose(): Closes an opened file.
  • perror(): Prints an error message associated with the current value of errno.

Common file modes include r for reading, w for writing, and a for appending. Writing with mode w truncates an existing file.

18. Preprocessor Directives

Definition: Preprocessor directives are instructions processed before the main compilation stage. They commonly include headers and define macros. 


#include <stdio.h>

#define MAX 100

#ifndef MAX
#define MAX 50
#endif
  • #include: Includes header contents.
  • #define: Defines a macro.
  • #ifdef: Checks whether a macro is defined.
  • #ifndef: Checks whether a macro is not defined.
  • #endif: Ends a conditional preprocessor section.

19. Storage Duration and Scope

Definition: Scope determines where an identifier can be accessed. Storage duration determines how long an object's storage exists. 


int globalValue = 10;

void example(void) {
    int localValue = 20;
    static int count = 0;

    count++;

    printf("%d %d %d\n",
           globalValue, localValue, count);
}
  • Local variable: Typically has block scope and automatic storage duration.
  • Global variable: Declared outside functions and usually has file scope.
  • static local variable: Retains its value between function calls.
  • extern: Declares an identifier that may be defined elsewhere.
  • register: A storage-class specifier with limited practical use in modern C.

20. Type Casting

Definition: Type casting converts a value from one data type to another. 


int a = 5;
int b = 2;

float result1 = a / b;
float result2 = (float)a / b;

printf("%f\n", result1);
printf("%f\n", result2);

The first result is 2.000000 because integer division happens before conversion to float. The second result is 2.500000 because a is converted to float before division.

21. Common Header Files

Definition: Header files provide declarations for functions, types, and macros that a program can use.

  • stdio.h: Standard input and output.
  • stdlib.h: Memory allocation, conversions, and general utilities.
  • string.h: String and memory manipulation functions.
  • math.h: Mathematical functions such as sqrt() and pow().
  • ctype.h: Character testing and conversion functions.
  • stdbool.h: Boolean aliases and constants in C99 and later.
  • time.h: Date and time utilities.
  • limits.h: Integer type limits.
  • float.h: Floating-point type characteristics.

22. Comments

Definition: Comments explain code to human readers. The compiler ignores comments during normal compilation. 


// This is a single-line comment.

/*
   This is a
   multi-line comment.
*/

int age = 24;

23. Compile and Run a C Program

Definition: Compilation translates C source code into an executable program that can be run on a compatible system. 


gcc main.c -o main

./main

On Windows, the executable may be run using: 


gcc main.c -o main.exe

main.exe
  • gcc: Invokes the GNU C compiler.
  • main.c: The C source file.
  • -o: Specifies the output filename.
  • ./main: Runs the executable on Linux or macOS.

24. Escape Sequences

Definition: Escape sequences represent special characters inside character and string literals. 


printf("Hello\nWorld");
printf("Name:\tTushar");
printf("He said \"Hello\"");
printf("Backslash: \\");
  • \n: New line.
  • \t: Horizontal tab.
  • \\: Backslash character.
  • \": Double quotation mark inside a string.
  • \': Single quotation mark.
  • \0: Null character.

25. Important Tips

  • End statements with a semicolon where required.
  • Use meaningful variable and function names.
  • Initialize variables before reading their values.
  • Check array boundaries before accessing elements.
  • Check the return values of input, file, and memory allocation functions.
  • Free dynamically allocated memory when it is no longer needed.
  • Use fgets() for safer line-based text input.
  • Compile with warnings enabled, for example gcc -Wall -Wextra -Wpedantic main.c -o main.
  • Avoid undefined behavior, such as dereferencing invalid pointers or accessing arrays out of bounds.
