JavaScript Cheat Sheet

JavaScript is a programming language used to make websites interactive and dynamic. It can handle user interactions, manipulate webpage content, validate forms, and communicate with servers.

1. Variables

Definition: Variables are containers used to store data in a program. JavaScript provides three keywords for declaring variables: let, const, and var. 


let name = "Tushar";
const age = 24;
var city = "Delhi";
  • let: Declares a block-scoped variable that can be reassigned.
  • const: Declares a block-scoped variable that cannot be reassigned.
  • var: Declares a function-scoped variable. It is generally avoided in modern JavaScript.

Note: A const object or array can still have its properties or elements changed, even though the variable cannot be reassigned.

2. Data Types

Definition: Data types describe the kind of value a variable contains. JavaScript has primitive data types and the Object type.

  • String: Represents text, such as "Hello".
  • Number: Represents integers and decimal numbers, such as 10 or 3.14.
  • Boolean: Represents either true or false.
  • Undefined: Represents a variable that has been declared but has not been assigned a value.
  • Null: Represents an intentional absence of a value.
  • Object: Stores related data as properties and values.
  • Array: Stores an ordered collection of values. Arrays are a type of object.

let username = "Tushar";  // String
let score = 100;          // Number
let isActive = true;      // Boolean
let result;               // Undefined
let selected = null;      // Null

3. Input

Definition: Input allows a program to receive data from users. In a webpage, JavaScript can read the value entered into an HTML input field using the DOM. 


const value = document.querySelector("#input").value;

Explanation:

  • document.querySelector("#input") selects the element with the ID "input".
  • .value retrieves the current value entered by the user.

Example HTML: 


<input type="text" id="input" placeholder="Enter your name">

4. Conditions

Definition: Conditional statements allow a program to make decisions. They execute different blocks of code depending on whether a condition is true or false. 


if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}
  • if: Executes code when a condition is true.
  • else: Executes code when the if condition is false.
  • else if: Checks another condition when the previous condition is false.

You can also use the switch statement when you need to compare one value against several possible cases. 


const day = "Monday";

switch (day) {
    case "Monday":
        console.log("Start of the week");
        break;
    case "Friday":
        console.log("Almost the weekend");
        break;
    default:
        console.log("Another day");
}

5. Loops

Definition: Loops repeatedly execute a block of code while a condition is satisfied or until a sequence has been processed. 


for (let i = 0; i < 5; i++) {
    console.log(i);
}

while (condition) {
    // code
}
  • for loop: Repeats code with initialization, a condition, and an update expression.
  • while loop: Repeats code as long as its condition remains true.
  • do...while loop: Executes the code at least once before checking the condition.
  • for...of: Iterates over values in iterable objects, such as arrays and strings.
  • for...in: Iterates over enumerable property keys of an object.

6. Functions

Definition: A function is a reusable block of code designed to perform a particular task. Functions can accept inputs called parameters and return an output. 


function add(a, b) {
    return a + b;
}

const multiply = (a, b) => {
    return a * b;
};
  • Function declaration: Defines a function using the function keyword.
  • Parameters: Variables that receive values passed to a function.
  • Arguments: Actual values supplied when calling a function.
  • return: Sends a result back to the caller.
  • Arrow function: A shorter function syntax that uses the => operator.

console.log(add(5, 3));       // 8
console.log(multiply(4, 2));  // 8

7. Arrays

Definition: An array is a data structure used to store multiple values in an ordered list. Each element has an index, starting from zero. 


const fruits = ["Apple", "Banana", "Mango"];

fruits.push("Orange");
fruits.pop();

fruits.map(item => console.log(item));

fruits.filter(item => item !== "Apple");
  • push(): Adds an element to the end of an array.
  • pop(): Removes and returns the last element.
  • map(): Creates a new array by transforming each element.
  • filter(): Creates a new array containing elements that satisfy a condition.
  • length: Returns the number of elements in an array.
  • find(): Returns the first element that satisfies a condition.
  • includes(): Checks whether an array contains a specified value.

const numbers = [1, 2, 3, 4, 5];

console.log(numbers.length);               // 5
console.log(numbers.includes(3));          // true
console.log(numbers.map(n => n * 2));      // [2, 4, 6, 8, 10]
console.log(numbers.filter(n => n > 3));   // [4, 5]

8. Objects

Definition: An object stores related information as key-value pairs. It is useful for representing real-world entities, such as users, products, and employees. 


const user = {
    name: "Tushar",
    age: 24
};

console.log(user.name);
  • Properties: Named values stored inside an object.
  • Dot notation: Accesses a property using its name, such as user.name.
  • Bracket notation: Accesses a property using brackets, such as user["age"].
  • Methods: Functions stored as object properties.

const product = {
    name: "Laptop",
    price: 50000,

    displayInfo() {
        console.log(this.name, this.price);
    }
};

product.displayInfo();

9. DOM (Document Object Model)

Definition: The DOM is a programming interface that represents an HTML document as a tree of objects. JavaScript uses it to access, change, add, and remove webpage elements. 


const element = document.querySelector("#title");

element.textContent = "Hello";

element.classList.add("active");

element.addEventListener("click", () => {
    console.log("Clicked");
});
  • querySelector(): Selects the first element matching a CSS selector.
  • textContent: Gets or sets the text content of an element.
  • classList.add(): Adds a CSS class to an element.
  • addEventListener(): Runs a function when a specified event occurs.
  • innerHTML: Gets or sets an element's HTML content. Use carefully with untrusted input.
  • createElement(): Creates a new HTML element.

Example HTML: 


<h2 id="title">Original Title</h2>
<button id="btn">Click Me</button>

10. Fetch API

Definition: The Fetch API allows JavaScript to make HTTP requests to servers. It is commonly used to retrieve data from APIs and send information to a server. 


fetch("https://example.com/api")
    .then(response => {
        if (!response.ok) {
            throw new Error("Request failed");
        }

        return response.json();
    })
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.log(error);
    });
  • fetch(): Sends an HTTP request and returns a Promise.
  • Promise: Represents the eventual success or failure of an asynchronous operation.
  • response.ok: Indicates whether the HTTP status is in the 200–299 range.
  • response.json(): Reads the response body and parses it as JSON.
  • then(): Handles a fulfilled Promise.
  • catch(): Handles errors or rejected Promises in the chain.

Important: Fetch does not automatically reject its Promise for HTTP errors such as 404 or 500. Check response.ok to handle those responses.

11. Async and Await

Definition: Async and await provide a more readable way to work with Promises. They are commonly used when fetching data from APIs or performing other asynchronous operations. 


async function getData() {
    try {
        const response = await fetch("https://example.com/api");

        if (!response.ok) {
            throw new Error("Request failed");
        }

        const data = await response.json();

        console.log(data);
    } catch (error) {
        console.error(error);
    }
}

getData();
  • async: Declares a function that returns a Promise.
  • await: Waits for a Promise to settle before continuing inside the async function.
  • try...catch: Handles errors that occur during execution.

12. Events

Definition: Events are actions or occurrences detected by the browser, such as clicks, keyboard input, form submissions, and page loading. JavaScript can respond to these events. 


const button = document.querySelector("#btn");

button.addEventListener("click", () => {
    alert("Button clicked!");
});
  • click: Occurs when an element is clicked.
  • input: Occurs when the value of an input element changes through user interaction.
  • submit: Occurs when a form is submitted.
  • keydown: Occurs when a key is pressed.
  • change: Occurs when an input's value change is committed.

13. Error Handling

Definition: Error handling allows you to detect and manage errors so that your program can respond appropriately instead of failing unexpectedly. 


try {
    let result = 10 / 0;

    console.log(result);
} catch (error) {
    console.error("An error occurred:", error);
} finally {
    console.log("Execution completed");
}
  • try: Contains code that may throw an error.
  • catch: Handles an error thrown in the try block.
  • finally: Runs after try and catch, whether an error occurred or not.
  • throw: Creates an error or throws another value explicitly.

Note that dividing a JavaScript number by zero returns Infinity; it does not throw an error by itself.

14. Local Storage

Definition: Local Storage is a browser feature that allows websites to store key-value pairs on a user's device. The data normally remains available after the browser is closed and reopened. 


localStorage.setItem("username", "Tushar");

const username = localStorage.getItem("username");

console.log(username);

localStorage.removeItem("username");

// Remove all entries for this website:
// localStorage.clear();
  • setItem(): Stores a value under a specified key.
  • getItem(): Retrieves a stored value.
  • removeItem(): Removes a specific key and its value.
  • clear(): Removes all local storage entries for the current origin.

Local Storage stores values as strings. Avoid storing passwords, access tokens, or other sensitive information in it.

15. JSON

Definition: JSON (JavaScript Object Notation) is a text format used to exchange structured data between applications and servers. 


const user = {
    name: "Tushar",
    age: 24
};

const jsonString = JSON.stringify(user);

console.log(jsonString);

const parsedUser = JSON.parse(jsonString);

console.log(parsedUser.name);
  • JSON.stringify(): Converts a JavaScript value into a JSON string.
  • JSON.parse(): Converts a valid JSON string into a JavaScript value.

Important Tips

  • Use const by default and let when reassignment is necessary.
  • Use meaningful variable and function names.
  • Prefer strict equality (===) when comparing values.
  • Use browser developer tools to debug JavaScript.
  • Handle errors when working with APIs and asynchronous code.
  • Never expose API keys, passwords, or private credentials in client-side JavaScript.
